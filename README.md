# Решения заданий курса Stepik

В этом репозитории собраны решения практических заданий курса [«Автоматизация тестирования с помощью Selenium и Python» на Stepik](https://stepik.org/575).

## Структура

- `lesson_1/` — решения заданий первого урока.
- `lesson_2/` — решения заданий второго урока.
- `lesson_3/` — каталог для решений третьего урока.

Файлы с решениями находятся в соответствующих каталогах уроков. Их имена помогают соотнести скрипт с заданием курса.

## Запуск

Скрипты написаны на Python. Чтобы запустить решение, перейдите в корень репозитория и выполните, например:

```bash
python lesson_1/1_6_1.py
```

Для заданий с Selenium установите зависимости курса и настройте браузер и драйвер, если они требуются конкретному скрипту.
